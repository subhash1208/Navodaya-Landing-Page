# Hero cup references

Branded paper-cup product shots for the hero section.
Generated with Google AI Studio (Gemini), September 2026.

Native size: 1024 × 1024 for all three — `cup-front.jpg` (front-on),
`cup-three-quarter.jpg` (three-quarter angle), `cup-rim-seam.jpg` (rim/seam
close-up).

**Do not upscale these.** AI upscalers mangle the wordmark letterforms. This is
why they are excluded from the Upscayl pass described in
`public/textures/README.md`.
