# Hero cup references

Branded paper-cup product shots for the hero section.
Generated with Google AI Studio (Gemini), September 2026.

Stored as `cup-front.webp` (front-on), `cup-three-quarter.webp` (three-quarter
angle) and `cup-rim-seam.webp` (rim/seam close-up), all 3072 × 3072. Native
generation size was 1024 × 1024.

**These have been upscaled — Ultramix Balanced at 3x.** An earlier revision of
this file said they must never be upscaled, on the grounds that AI upscalers
mangle the two-line wordmark. That was tested rather than argued and the
instruction was overturned on 2026-09-24: Ultramix Balanced holds the
letterforms cleanly. **Ultrasharp remains unsuitable for these three files**
because it over-sharpens text. The full ruling, including the limits of the
verification, is in `public/textures/README.md`.
